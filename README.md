# Academic Hub

A clean starter website for an academic department, lab, or student organization.

## Features
- Responsive homepage
- About, programs, research, space education/activities, events, and contact sections
- Contact form with speaker request or general contact options
- Hosted form service integration for direct submissions
- Simple HTML, CSS, and JavaScript

## Contact form
The form is connected to FormSubmit and sends submissions to `bd520@cam.ac.uk`.
The first submission may trigger a confirmation email from the form service.

## Run locally
Just open `index.html` in your browser.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload these files.
3. In repository settings, enable GitHub Pages from the main branch.

## Customize
Replace placeholder text, phone number, and colors with your own details.
