# Bram de Winter — Academic Website

A polished one-page academic website ready for GitHub Pages.

## What is included
- Hero section with your photos
- About, Research, Publications, Space Education, Gallery, and Contact sections
- Speaker request / general contact form
- Hosted form submission via FormSubmit to bd520@cam.ac.uk

## How to publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload all files in this folder so that `index.html` is in the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Save and wait for the deployment link.

## Contact form note
The contact form uses FormSubmit. The first time it is used, FormSubmit may ask for a confirmation step for the email destination.
